### 🚀 Featured Software Project: Wireless Link Simulator

I built a complete BPSK communication link simulator from scratch in MATLAB to answer a specific question: *How do wireless channels affect communication reliability?*

- **Core:** Simulated BPSK over AWGN and Rayleigh fading channels.
- **Diversity:** Implemented 2-branch Maximal-Ratio Combining (MRC) to overcome deep signal fades.
- **Novel Analysis:** Explored realistic impairments, including MMSE pilot-based channel estimation (Imperfect CSI) and spatial correlation between antennas (\(\rho = 0.8\)).
